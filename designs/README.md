# Research Navigator – UI designs

This folder holds [Pencil](https://pencil.app) design files (`.pen`) for the Research Navigator UI.

## How to use Pencil with this project

1. **In Cursor** – Pencil is available via MCP. Ask the AI to “open the Research Navigator design” or “design the login screen in Pencil” and it can work in `research-nav-ui.pen`.

2. **Design file** – `research-nav-ui.pen` is the main UI design file. Open it in Pencil (or have Cursor open it) to create or edit screens for:
   - Login / signup
   - Lab dashboard (papers, graph, recommendations)
   - Paper detail

3. **From design to code** – Use Pencil’s code guidelines (e.g. Tailwind) to generate or align implementation in `apps/web/src`.
